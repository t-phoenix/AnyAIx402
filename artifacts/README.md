# Artifacts directory

Orchestrator and specialists write task briefs, bugs, reviews, marketing drafts, and deploy logs here.

- `tasks/` — TASK-*.md, BLOCKED-*.md
- `bugs/` — BUG-*.md
- `reviews/` — security/product/research notes
- `marketing/` — content drafts (not auto-published)
- `deploys/` — health checks and release notes

Do not store secrets here.
